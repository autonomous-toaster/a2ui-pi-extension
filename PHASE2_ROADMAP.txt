KEYBOARD MAPPINGS (Unified)

  NAVIGATION:
    Tab / Shift+Tab  ← Move between fields
    ↑ / ↓            ← Navigate options / items
    → / ←            ← Expand/collapse (accordion, dropdown)
    Home / End       ← Jump to first/last
    Page Up / Down   ← Scroll by 5

  INPUT:
    Space            ← Toggle checkbox, expand accordion
    Enter            ← Submit, navigate, confirm
    Backspace        ← Delete char, clear search
    Escape           ← Cancel, close dropdown

  TYPING:
    Any char (a-z)   ← Add to field, filter list, search
    Ctrl+A           ← Select all (textarea)
